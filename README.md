# Link Risk Detector

## Project Overview
Link Risk Detector is a web-based project designed to analyze URLs and identify potentially suspicious links.

## Objectives
- Analyze a URL for suspicious characteristics.
- Display a risk level: Low, Medium, or High.
- Help users recognize potentially unsafe links.

## Technologies Used
- HTML
- CSS
- JavaScript

## How It Works
1. The user enters a URL.
2. The website analyzes URL characteristics.
3. A risk level is displayed based on the implemented checking logic.

## Current Implementation
The current version uses client-side URL checking logic. A separate Python backend and trained machine learning model are not yet implemented.

## Future Scope
- Develop a Python backend API.
- Integrate a trained machine learning model.
- Test the detector using a labeled dataset.
